# Google Play first release checklist

- [ ] Developer account and identity verification complete; create **KAAM** with `com.kaamperfectmatch.kaam_perfect_match`.
- [ ] Confirm label, 512×512 icon, feature graphic, screenshots, description, support email, privacy-policy URL, UAE/India availability, price, and test credentials.
- [ ] Complete app access, ads, content rating, target audience, data safety, privacy policy, and account-deletion disclosure/process.
- [ ] Back up the upload keystore and passwords securely in two locations; enable Play App Signing.
- [ ] Verify Firebase app registration and Google Sign-In OAuth release SHA-1/SHA-256 for the upload/app-signing certificate.
- [ ] Upload signed production AAB to Internal Testing; run pre-launch report and test sign-in, OTP, FCM, deep links, notification channels, flexible updates and immediate updates.
- [ ] Complete closed testing if the account requires it, select countries/regions, then submit the release for review.
