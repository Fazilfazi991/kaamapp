# KAAM Employer Candidate Search

Open `index.html` in a modern browser to view the complete mobile prototype.

The desktop preview rail exposes all requested deliverables: default search, expanded filters, candidate matching, score explanation, full profile, no-results, completed-review, and saved-candidate screens. A ninth preview entry demonstrates the required recoverable error state. On a phone-sized viewport, use the floating grid button to switch between prototype states.

The prototype also includes skeleton loading, offline feedback, removable recent searches, editable filters, labeled match actions, swipe gestures, action locking, confirmation toasts, protected contact information, and preserved employer navigation.
